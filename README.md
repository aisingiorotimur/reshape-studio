# RE/SHAPE

一个完全在浏览器本地运行的图片工具，单文件静态网页，无需构建、无需后端。

在线体验：https://aisingiorotimur.github.io/reshape-studio/

## 功能

- **调整大小**：按像素输入宽高，可锁定/解锁比例，随时还原为原图
- **自动分割**：自动识别一张图里的多张独立照片（例如扫描件、拼贴图、九宫格），沿背景边框把它们分割成单独的图片
  - 优先按网格线（背景色的整行/整列空隙）切分，网格不明显时退回到前景色块检测
  - 灵敏度可调，并提供检测调试视图（高亮识别出的前景区域），方便在检测不准时排查原因
- 每张分割结果可单独再调整尺寸并下载 PNG，也可一键打包下载全部结果（ZIP）
- 支持 JPG、PNG、WebP、GIF、BMP 导入
- 图片始终只在浏览器本地处理，不会上传到任何服务器

## 本地开发

不需要构建工具，用任意静态服务器打开 `index.html` 即可，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 部署

仓库通过 GitHub Pages 从 `main` 分支根目录直接发布 `index.html`。
