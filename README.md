# RE/SHAPE

一款完全在浏览器内运行的图片形变工作台。它把调整尺寸、比例裁切、旋转和翻转记录成可回放时间线，并把压缩后的图片与历史一起编码进分享链接。

## 功能

- JPG、PNG、WebP、GIF 等图片导入与自动优化
- 锁定或解锁比例的尺寸调整
- 常用裁切比例与九宫格构图焦点
- 90° / 180° 旋转、水平 / 垂直翻转
- 最多 100 步非破坏式历史、撤销 / 重做、任意节点预览
- PNG 导出
- 自包含分享快照：收件人可浏览完整历史并继续编辑
- 桌面端、平板和移动端响应式界面

## 分享模型

分享链接是一个不可变、自包含的快照，而不是实时协作房间。

- 图片和历史位于 URL 的 `#s=` 片段中，不会发送给 RE/SHAPE 服务器。
- 接收者的编辑不会修改原链接；再次分享会生成一个新快照链接。
- 任何获得链接的人都可以查看其中的图片和历史，因此不应分享敏感图片。
- 导入图片会被优化为最长边不超过 1600px、约 500KiB，以控制链接长度。

## 本地开发

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

验证：

```bash
npm test
npm run lint
npx tsc --noEmit
```

## 技术栈

React 19、TypeScript、vinext / Vite，以及原生 Canvas、CompressionStream 与 URL fragment。站点由 OpenAI Sites 托管，图片编辑不依赖后端数据库或对象存储。
